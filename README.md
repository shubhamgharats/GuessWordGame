# Guess Word Game

A Hangman-style word guessing game built while learning **React**. The game generates a random word, provides AI-powered hints, and challenges players to guess the word before running out of lives.

**Live Demo:** https://your-vercel-link.vercel.app

## What I Learned

While building this project, I gained hands-on experience with:

- React functional components and JSX
- State management using `useState`
- Conditional rendering and dynamic UI updates
- Event handling and user interactions
- Rendering lists with `map()`
- Immutable state updates
- JavaScript array methods (`map`, `some`, `every`, `includes`, `slice`)
- Fetching data from external APIs
- Asynchronous programming with `async/await`
- AI integration using the OpenRouter API
- Prompt engineering for generating contextual hints
- Loading and error state management
- Responsive UI development with Tailwind CSS
- Structuring a complete React application into reusable components

## Getting Started

Clone the repository:

```bash
git clone https://github.com/shubhamgharats/GuessWordGame.git
cd GuessWordGame
```

Install dependencies:

```bash
npm install
```

Create a `.env` file:

```env
VITE_OPENROUTER_API_KEY=your_api_key
```

Run the development server:

```bash
npm run dev
```
